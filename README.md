# TypeSafe AI (Jev Model) Python Demo

A minimal, production-ready example demonstrating how to use **Jev** — TypeSafe AI's System-1 model designed for fast (~100ms), typed, and deterministic decision-making instead of free-form text generation.

---

## 📌 Project Overview

This repository demonstrates how to integrate the official `typesafe-sdk` to evaluate structured input states against typed primitives:
- **`Choice`**: Selects from predefined categories with confidence scores.
- **`Score`**: Assesses values on a discrete scale (e.g., Urgency).
- **`Noul`**: Computes boolean (Yes/No) probabilities.
